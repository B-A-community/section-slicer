# Section Slicer — сечения по отметкам

Плагин SketchUp: горизонтальные сечения выбранной группы или компонента на заданных отметках. Каждое сечение становится гранями с площадью, сечения раскладываются рядом с моделью снизу вверх, площади сводятся в таблицу, которая вставляется в Excel и Google Таблицы по ячейкам.

Версия **0.1.0**. Код написан под Ruby API SketchUp 2021+. Проверено только в **SketchUp 2024 Pro 24.0.484, Ruby 3.2.2, Windows**: 42 автоматические проверки в живом SketchUp, см. [docs/testing.md](docs/testing.md). Версии 2021–2023, 2025–2026 и macOS не проверялись.

Техническое задание: [ТЗ плагин SketchUp «Сечения по отметкам».pdf](ТЗ%20плагин%20SketchUp%20«Сечения%20по%20отметкам».pdf).

Авторы: [maksarsanjeev](https://github.com/maksarsanjeev), [Royalb21](https://github.com/Royalb21). Правообладатель — B&A community. [Apache License 2.0](LICENSE).

## Как работать

1. Выделите **одну** группу или компонент и запустите **Extensions → Section Slicer → Сечения по отметкам**, кнопку панели или пункт контекстного меню. Горячую клавишу можно назначить в Window → Preferences → Shortcuts.
2. Плоскость следует за курсором. Клик по вершине, ребру или грани фиксирует её на Z этой точки. Отметку можно набрать в Measurements: `3000` — абсолютная, `+500` / `-500` — от последней плоскости.
3. **N** или «Добавить» — ещё одна плоскость. В окне у каждой плоскости есть отметка, **шаг** (может быть отрицательным) и **число копий**; копии рисуются сразу.
4. **Enter** или «Построить сечения».

| Действие | Способ |
|---|---|
| Новая плоскость | N или «Добавить», затем клик |
| Перепривязать | кнопка ⌖ в строке, затем клик |
| Удалить | ✕ в строке или Delete (активная плоскость) |
| Отменить действие с плоскостями | Esc, «Отменить» или Ctrl+Z (см. ниже) |
| Построить | Enter или «Построить сечения» |

Активная плоскость оранжевая, остальные синие, копии бледнее, вне габарита — серые с подписью «вне габарита»; при построении они пропускаются с сообщением. Отметки, совпадающие в пределах 0,1 мм, сливаются. Все плоскости и копии сортируются снизу вверх и нумеруются 1…N.

**Ctrl+Z** при активном инструменте: если последней операцией было построение, отменяется только оно (одним шагом), плоскости остаются. Иначе откатывается последнее действие с плоскостями — но SketchUp при этом всё равно отменяет и последнюю операцию модели, поэтому для плоскостей надёжнее Esc или кнопка «Отменить».

## Результат

- Общая группа `Сечения · <имя объекта>` в текущем контексте, внутри — группа `Сечение №n · +3 000` на каждое сечение и подписи с номером, отметкой и площадью.
- Сечения лежат на Z = 0 правее габарита объекта: в ряд или сеткой (число столбцов), отступ — процент ширины объекта (по умолчанию 20%). Каждая ячейка повторяет план габарита объекта, поэтому сечения разных отметок совпадают при наложении.
- Внутри — только грани и их рёбра, лицом вверх. Отверстия (атриумы, шахты, дворы) — вырезы в грани, острова внутри них — отдельные грани.
- Незамкнутый контур оставляет рёбра без грани; сечение помечается «есть разрывы».
- Всё построение — одна операция, отменяется одним Ctrl+Z. Повторное построение создаёт новую группу и не трогает прежнюю.

## Таблица площадей

Строка на каждый контур (грань), жирный итог по сечению и общий итог. Колонки: № сечения, отметка, № контура (`3.2`), площадь, периметр (внешний + внутренние контуры), статус.

- Клик по строке открывает группу сечения и выделяет грань; по итогу — выделяет группу сечения.
- **Копировать** кладёт таблицу в буфер сразу как текст (TSV) и HTML — вставка в Excel / Google Таблицы раскладывается по ячейкам, номер контура остаётся текстом, отметки и площади — числами.
- **Экспорт CSV**: UTF-8 с BOM; при десятичной запятой разделитель полей `;`, иначе `,`.
- Единицы площади: м², см², мм², ft²; десятичный разделитель — системный или выбранный.
- Таблица хранится в атрибутах общей группы. Выделите такую группу и выберите **Таблица площадей сечений** — таблица откроется снова, в том числе после перезагрузки модели.

## Как считаются сечения

- Исходная модель только читается: грани собираются рекурсивно из всех вложенных групп и компонентов с учётом трансформаций (масштаб, поворот, зеркало). Скрытые объекты и выключенные теги пропускаются.
- Пересечение с плоскостью считается собственным кодом, без временной геометрии. Отрезки сшиваются с допуском 0,1 мм.
- **Вложенные тела объединяются**, как на плане: соприкасающиеся, пересекающиеся и вложенные друг в друга группы дают один общий контур без внутренних линий.
- Вершина ровно на секущей плоскости считается лежащей чуть ниже: срез на отметке пола даёт план этажа над ней. На верхней отметке объекта — наоборот, срез по крыше даёт её контур.
- Незамкнутое тело (не solid) — предупреждение, сечение строится по тем граням, что есть. Группа из вложенных солидов считается телом.
- Отметки — мировые Z, в единицах модели (мм, см, м, дюймы, футы). Объект можно выбирать и внутри открытой группы.

Решения по открытым вопросам ТЗ: плоскости только горизонтальные; сечение строится объединённо по всем вложенным группам.

## Установка и разработка

Готовые RBZ не публикуются. Сборка:

```bash
powershell -ExecutionPolicy Bypass -File tools/build_rbz.ps1
```

Результат — `build/section_slicer0.1.0_test.rbz`, устанавливается через **Extension Manager → Install Extension**.

Исходники прямо в SketchUp 2024 (предыдущая версия сохраняется в `build/installed-backup-*`):

```bash
powershell -ExecutionPolicy Bypass -File tools/dev_install.ps1
```

Полный прогон проверок в открытом SketchUp 2024 через мост sketchup-mcp на `localhost:8080` (тестовые объекты создаются и удаляются сами, буфер обмена сохраняется и восстанавливается; Excel нужен для последнего шага, иначе `-SkipExcel`):

```bash
powershell -ExecutionPolicy Bypass -File tools/test_su2024.ps1
```

Иконки: `python tools/generate_icons.py` (SVG для Windows, PNG для macOS).

## Релизы и обновления через Exterminatus

Плагин ставится и обновляется лаунчером [Exterminatus](https://github.com/B-A-community/exterminatus) из релизов этого репозитория. Кода для обновлений в плагине нет. Подробнее — раздел Exterminatus в [CLAUDE.md](CLAUDE.md).

1. Поднять `VERSION` в `src/section_slicer.rb`.
2. Собрать ассет: `powershell -ExecutionPolicy Bypass -File tools/build_rbz.ps1 -Release` → `build/release/section-slicer-<версия>-rus.rbz` (язык — из `src/section_slicer/lang.rb`).
3. Релиз на GitHub: тег `vX.Y`, ассет из шага 2, не черновик и не pre-release.

Имя расширения `Section Slicer`, папка `section_slicer` и строка `LANG = 'ru'` в `lang.rb` не меняются — по ним Exterminatus находит плагин и его языковую сборку.

## Ограничения версии 0.1.0

- Только горизонтальные плоскости.
- Грани тоньше 0,1 мм сшиваются в точку; детали тоньше ~0,1 мм могут теряться.
- Совпадающие двойные грани внутри одного тела гасят друг друга (так убираются дубли); у тела с внутренними перегородками без толщины контур может получиться неожиданным.
- Таблица ссылается на грани по persistent id: после ручной правки сечений клик по строке может не найти грань.
- macOS: копирование только текстом (TSV) через `pbcopy`, иконки PNG; не проверялось.
