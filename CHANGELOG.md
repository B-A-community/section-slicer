# Changelog

## 0.1.0 — 2026-10-18

Первая рабочая версия по ТЗ «Сечения по отметкам».

- Инструмент секущих плоскостей: привязка к вершине/ребру/грани через InputPoint, ввод отметки в Measurements (абсолютно и от последней), N / Delete / Esc / Enter, перепривязка, массивы копий с шагом и количеством, слияние совпадающих отметок, плоскости вне габарита серым.
- Сечения без временной геометрии: рекурсивный сбор граней с трансформациями, сшивка 0,1 мм, объединение соприкасающихся и пересекающихся вложенных тел, вырезы и острова, разрывы рёбрами.
- Раскладка на Z = 0 правее модели в ряд или сеткой, подписи, одна операция Undo; Ctrl+Z после построения снимает только построение.
- Таблица площадей и периметров с итогами, клик по строке выделяет грань, копирование TSV + HTML (WinAPI / pbcopy), CSV, хранение в атрибутах и повторное открытие.
- EntitiesBuilder для граней с отверстиями (SketchUp 2022+), add_face для 2021.
- 42 проверки в живом SketchUp 2024, включая вставку в Excel.
